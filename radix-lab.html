One value, every base

Type a number in any base from 2 to 36, with or without a fractional part. Every other representation updates as you type, including the binary codes BCD, Excess-3 and Gray.

Key ideaIn base r, a digit in position k is worth digit × rk. Base 16 borrows the letters A–F for the digit values 10–15.
Input base

16-bit register

Click any bit. Each position carries a weight of 2k, and the value is the sum of the weights whose bit is 1.

Decimal to base r

The integer part is converted by repeated division, the fractional part by repeated multiplication. Step through the method or let it play.

Key ideaDividing by r peels off the lowest digit as the remainder. Multiplying a fraction by r pushes the next digit across the radix point.

Base r to decimal

Write each digit's place value as a power of the base, multiply, and add. Positions left of the point count up from 0; positions right of it count down from −1.

Key ideaN = Σ dk × rk. For 2F7.A16: 2×256 + 15×16 + 7×1 + 10×1/16 = 759.625.
Its base

Binary, octal and hex by grouping

No arithmetic needed. Group bits outward from the radix point, three at a time for octal and four at a time for hexadecimal, or expand each digit back into bits.

Key idea8 = 23 and 16 = 24, so one octal digit is exactly 3 bits and one hex digit is exactly 4 bits. To go octal ↔ hex, pass through binary.

Signed numbers

With n bits there are 2n patterns. Each signed scheme decides which patterns mean negative values. Move the slider or click the bits and compare the four schemes side by side.

Key ideaIn 2’s complement the MSB has weight −2n−1 and every other bit keeps its usual positive weight. That single rule explains the range, the negation trick and why one adder serves addition and subtraction.

Read a bit pattern

Click bits to build a pattern. The same bits mean different values depending on the scheme. Weights shown are for 2’s complement.

Forming the 2’s complement

Negate by inverting every bit, then adding 1. Uses the value chosen above.

The 4-bit number wheel

Sixteen patterns arranged in a circle. Adding 1 moves one step clockwise. The dashed line marks where the value jumps: crossing it is overflow.

Click a pattern or use ±1.

Sign extension

To widen a 2’s complement number, copy its sign bit into every new position. Padding with zeros only works for non-negative values.

Binary arithmetic

Watch a ripple-carry adder work column by column. Subtraction reuses the same adder, and the status flags tell you whether the answer fits in the word.

Key ideaA − B = A + ¬B + 1. Signed overflow happens exactly when the carry into the MSB differs from the carry out of it: V = Cn−1 ⊕ Cn.
